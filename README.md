# VVIA Extrato — demonstração

Demonstração das telas do sistema de extratos bancários (classificação dos lançamentos
e arquivo TXT para o Domínio Contábil), feito para a Valls & Vargas.

**Todos os dados são fictícios** (empresa, contas e valores inventados) e ficam só no
navegador: nada é gravado, e ao atualizar a página tudo volta ao começo.

Acesse: https://laylascherer.github.io/extratoleme-demo/
